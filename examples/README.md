## 示例插件概览

### 🔍 元数据提取器 (metadata-extractor)
**类型**：基础功能插件  
**功能**：从归档文件名、目录结构和基础属性中自动提取元数据并生成标签

**主要特性**：
- 可配置的正则表达式模式匹配
- 文件名解析（作者、系列、语言等）
- 目录结构分析（分类推断）
- 基础标签生成（格式、分辨率、语言）
- 置信度评分系统
- 自动标签应用

**学习目标**：
- 插件配置系统使用
- 数据库操作和标签管理
- 异步编程模式
- 错误处理最佳实践

### 🖼️ 图像处理器 (image-processor)
**类型**：高级功能插件  
**功能**：高级图像处理和优化，支持格式转换、质量控制和批量处理

**主要特性**：
- 多种处理模式（优化、增强、调整大小）
- 格式转换（WebP、JPEG、PNG）
- 并行批处理（基于 Rayon）
- REST API 接口
- 实时进度监控
- 定时任务支持
- 数据库集成

**高级特性**：
- 自定义 API 端点注册
- 后台任务处理系统
- 复杂的配置管理
- 性能优化技术

**学习目标**：
- 复杂插件架构设计
- REST API 集成
- 并行处理和性能优化
- 任务队列和进度监控
- 自定义端点注册

## 插件开发快速入门

### 1. 选择合适的示例
- **新手开发者**：从 `metadata-extractor` 开始，学习基础概念
- **有经验开发者**：可以直接参考 `image-processor` 了解高级特性

### 2. 环境准备
```bash
# 安装 Rust 开发环境
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 克隆项目
git clone https://github.com/your-org/otamoryx.git
cd otamoryx/examples/plugins

# 选择一个示例开始学习
cd metadata-extractor  # 或 image-processor
```

### 3. 构建和测试
```bash
# 构建插件
./build.sh

# 插件包会生成在 target/ 目录下
ls target/*.tar.gz
```

### 4. 安装和配置
1. 启动 OtamoryX 系统
2. 进入管理界面的"插件管理"页面
3. 上传生成的 `.tar.gz` 文件
4. 配置插件参数
5. 启用插件

## 插件开发指南

### 支持的插件类型
1. **元数据提取器** - 分析和提取内容元数据
2. **内容处理器** - 处理和转换归档内容
3. **外部集成器** - 与外部服务和 API 集成
4. **UI 扩展器** - 提供自定义用户界面
5. **分析器** - 内容分析和智能标签生成

### 插件能力
- ✅ **元数据提取** - 从文件中提取信息
- ✅ **归档处理** - 处理归档文件内容
- ✅ **自定义端点** - 注册 REST API 路由
- ✅ **定时任务** - 后台定时执行任务
- ✅ **数据库访问** - 读写系统数据库
- ✅ **文件系统访问** - 访问指定目录和文件

### 权限系统
插件采用声明式权限模型，必须在 `plugin.toml` 中声明所需权限：

```toml
[permissions]
network = false                    # 网络访问
filesystem_read = ["/path/*"]      # 文件系统读取
filesystem_write = ["/path/*"]     # 文件系统写入
database_read = true               # 数据库读取
database_write = ["table1", "table2"]  # 数据库写入
custom_endpoints = true            # 自定义 API 端点
scheduled_tasks = true             # 定时任务
```

## 最佳实践

### 开发建议
1. **从简单开始**：先实现基本功能，再添加复杂特性
2. **异步优先**：使用 async/await 处理 I/O 操作
3. **错误处理**：实现完善的错误处理和恢复机制
4. **配置验证**：验证用户配置的有效性
5. **资源清理**：正确清理内存和文件资源

### 性能优化
1. **并行处理**：使用 Rayon 进行 CPU 密集型并行计算
2. **缓存策略**：合理使用缓存减少重复计算
3. **内存管理**：避免内存泄漏，及时释放大对象
4. **批处理**：批量处理多个项目提高效率

### 安全考虑
1. **输入验证**：验证所有外部输入
2. **权限最小化**：只申请必要的权限
3. **敏感数据**：安全处理密码和密钥
4. **沙箱隔离**：插件运行在受限环境中

## 调试和故障排除

### 常见问题
1. **编译错误**：检查依赖版本和 Rust 工具链
2. **加载失败**：验证插件签名和权限声明
3. **运行时错误**：查看系统日志和错误信息
4. **性能问题**：使用性能分析工具优化代码

### 调试工具
- `cargo check` - 快速语法检查
- `cargo test` - 运行单元测试
- `cargo bench` - 性能基准测试
- 系统日志 - 查看运行时错误
