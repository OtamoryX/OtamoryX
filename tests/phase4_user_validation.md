### 3. 验证测试用例

#### 3.1 基本认证验证
- [ ] admin用户可以登录并获取JWT token
- [ ] user1可以登录并获取JWT token
- [ ] user2可以登录并获取JWT token
- [ ] 错误密码无法登录
- [ ] 不存在的用户无法登录

#### 3.2 权限隔离验证
- [ ] admin可以访问所有管理端点
- [ ] user1/user2无法访问管理端点
- [ ] user1/user2无法访问其他用户的数据
- [ ] 用户只能修改自己的信息

#### 3.3 路径权限验证
- [ ] user1只能访问manga路径下的档案
- [ ] user2只能访问novels路径下的档案
- [ ] admin可以访问所有路径的档案
- [ ] 跨路径访问被正确拒绝

#### 3.4 数据隔离验证
- [ ] 用户阅读进度互相隔离
- [ ] 用户创建的分类互相隔离
- [ ] 用户标签操作不影响其他用户

#### 3.5 管理员保护验证
- [ ] 不能删除最后一个管理员
- [ ] 不能将最后一个管理员降级
- [ ] 批量删除不能删除所有管理员

#### 3.6 安全审计验证
- [ ] 无token访问受保护端点被拒绝
- [ ] 过期token被正确拒绝
- [ ] 篡改token被正确拒绝
- [ ] SQL注入攻击被正确防护
