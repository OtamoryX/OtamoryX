# OtamoryX 开发路线图

更新日期：2026-10-07。

本路线图描述后续产品方向，不承诺交付日期。当前功能与部署方式以
[项目说明](../README_zh.md)、[开发指南](development.md)和
[部署指南](deployment.md)为准。

## 阅读与资料管理

- 改善跨设备阅读进度与历史记录体验。
- 完善版本组整理、回收站恢复和批量操作。
- 持续改善移动端阅读与标签浏览体验。

## 标签与推荐

- 完善自动标签、标签本地化与增量内容画像。
- 基于真实阅读反馈持续评估推荐效果。
- 独立评估标签关系模型，保留可解释的推荐依据与用户控制。

## 插件与客户端

- 完善外部插件运行、权限和开发工具。
- 探索桌面客户端与原生文件操作。

## 工程质量

- 持续改善认证、访问控制、稳定性和性能。
- 完善回归覆盖、运行指标和多语言支持。
